Spine Auxiliary Tools

离线可用的 Spine / Live2D 资源辅助工具。Extract, rebuild, and round-trip atlas images directly in your browser.

Spine Workflow

Spine 工具

面向 Spine `.atlas`、`.json` 和 Photoshop 往返编辑，覆盖解包切图、PSD 还原、切图回填图集三个环节。

atlas -> images -> PSD -> images -> atlas

Atlas / Images

Spine Atlas 切图工具

从 `.atlas` 与合图 PNG 中导出独立切图，可选 JSON 辅助按 attachment / UV 导出更细的图像。

  • 支持拖入 atlas、PNG、JSON
  • 处理 rotate、orig、offset
  • 输出 images.zip 与 atlas_manifest.json
打开工具 / Open Tool
JSON / Photoshop

Spine JSON 转 Photoshop JSX

读取 Spine JSON 的 bones、slots、skins 与附件信息，生成可在 Photoshop 中执行的图层重建脚本。

  • 按 setup pose 视觉还原
  • 保留 Spine slot 绘制顺序
  • 记录原始像素尺寸，支持逆向导出切图
打开工具 / Open Tool
Images / Atlas

Spine 切图还原图集

读取原 `.atlas`、原 page PNG 与修改后的切图，按原素材摆放烘回图集，输出可直接替换的 atlas PNG。

  • 使用 atlas_manifest.json 精确匹配切图
  • 支持 rotate、orig、offset 反向打包
  • 缺失切图可保留原图集底图
打开工具 / Open Tool
Live2D Workflow

Live2D 工具

面向 Cubism 导出包和 texture atlas，侧重从运行时数据近似重建 PSD，并把修改后的 ArtMesh 切图烘回原贴图。

model3 / moc3 -> PSD slices -> texture atlas

Live2D / Photoshop

Live2D 转近似分层 PSD

从 Cubism 导出包读取 moc3、model3.json、motion3.json 与贴图，生成 Photoshop JSX 和 ArtMesh 切图 ZIP。

  • 按 Live2D render order 生成图层顺序
  • 支持 motion3 姿态采样和 UV V 轴翻转
  • 单文件离线运行，内置 Cubism Core
打开工具 / Open Tool
Live2D / Texture

Live2D 切图反向还原图集

读取原 model3、moc3 与 textures，把修改后的 slices 按 ArtMesh UV 三角形烘回原 Live2D 图集。

  • 根据 moc3 drawable 顶点和 UV 反向映射
  • 优先使用 PSD 重建包的 manifest.json 精确定位切图
  • 输出路径与 model3.json 的 texture 引用一致
打开工具 / Open Tool

所有处理都在浏览器本地完成，不需要上传资源文件。All processing happens locally in your browser; asset files are not uploaded to a server.
