Spine Auxiliary Tools

离线可用的 Spine 资源辅助工具。Extract Spine atlas images and generate Photoshop JSX scripts directly in your browser.

Atlas / Images

Spine Atlas 切图工具

从 `.atlas` 与合图 PNG 中导出独立切图，可选 JSON 辅助按 attachment / UV 导出更细的图像。

  • 支持拖入 atlas、PNG、JSON
  • 处理 rotate、orig、offset
  • 输出 images.zip
打开工具 / Open Tool
PNG / Atlas

PNG Atlas Packer

Pack split PNG slices back into atlas PNG pages while keeping natural filename order by default.

  • Preserves original atlas order by filename
  • Exports atlas PNG pages plus JSON / TSV mapping
  • Optional padding, edge extrude, trim, and power-of-two pages
Open Tool
JSON / Photoshop

Spine JSON 转 Photoshop JSX

读取 Spine JSON 的 bones、slots、skins 与附件信息，生成可在 Photoshop 中执行的图层重建脚本。

  • 按 setup pose 视觉还原
  • 保留 Spine slot 绘制顺序
  • 生成可下载的 JSX
打开工具 / Open Tool
Live2D / Photoshop

Live2D 转近似分层 PSD

从 Cubism 导出包读取 moc3、model3.json、motion3.json 与贴图，生成 Photoshop JSX 和 ArtMesh 切图 ZIP。

  • 按 Live2D render order 生成图层顺序
  • 支持 motion3 姿态采样和 UV V 轴翻转
  • 单文件离线运行，内置 Cubism Core
打开工具 / Open Tool

所有处理都在浏览器本地完成，不需要上传资源文件。All processing happens locally in your browser; asset files are not uploaded to a server.
